# configs

## Как добавить цитаты

1. Возьми последний номер из `quotes_counter`.
2. Допиши новые цитаты в конец `daily_quotas`, пронумеровав их подряд со следующего номера.
3. Запиши в `quotes_counter` последний использованный номер.
4. Закоммить и запушь в `main`. Без push цитаты не появятся.

Чтобы заменить весь набор: перенеси текущий `daily_quotas` в `daily_quotas_N` (следующее
свободное N), положи в `daily_quotas` новые цитаты и дальше выполни шаги 1–4.

## Файлы

- `daily_quotas` — рабочий файл, читается только он.
- `daily_quotas_1`, `daily_quotas_2`, … — архив, нужен только для проверки на повторы.
- `quotes_counter` — последний выданный номер, одно число.

## Формат строки

Одна строка — одна цитата, без пустых строк. Файл заканчивается переводом строки.

```
N. «Текст цитаты». — Имя Персонажа, «Название произведения»
N. “Quote text.” — Character Name, “Title of the Work”
N. «Текст цитаты». — Имя Человека
```

Строка без номера `N. ` в начале пропускается.

## Нумерация

Номер — постоянный id цитаты, по нему отслеживается, показывалась ли она.

- Номера сквозные по всем файлам `daily_quotas*` и никогда не переиспользуются, даже после
  удаления строки.
- Новый набор не начинается с 1, номера продолжают `quotes_counter`.
- Новая цитата — всегда новый номер. Не меняй текст под старым номером.

## Подбор цитат по умолчанию

Применяется, только если в запросе не сказано иначе. Можно сослаться на этот раздел или отменить
любой пункт.

- 20 цитат за раз.
- Только реальные цитаты. Если не уверен в формулировке или авторе, не добавляй.
- Без повторов по всем `daily_quotas*`, включая ту же мысль другими словами.
- Не больше 2 цитат из одного источника за раз.
- Примерно 60% аниме и манга, 40% кино, книги, игры, философия.
- Англоязычные источники — дословно на английском, остальные — на русском.
- Каждая строка понятна без контекста, до ~200 символов, без заезженных и пустых «верь в себя».
- Без религии, политики, смерти и суицида.
