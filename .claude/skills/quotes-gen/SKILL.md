# Генератор ежедневных цитат

Пополняет файл цитат, из которого джоба каждое утро в 9:00 берёт случайную ещё не отправленную строку и шлёт в Telegram.

**Одна строка файла = одно утреннее сообщение.** Каждая строка должна работать в одиночку, без контекста соседних. Это и есть главный критерий качества.

## Аргументы

Из запроса пользователя извлеки:
- **количество** — сколько новых цитат добавить (по умолчанию 20)
- **целевой файл** — путь (по умолчанию `daily_quotas`)
- **тему/фокус** — необязательный фильтр («про упорство», «только аниме», «из игр»)

Дедуп идёт по **всем** файлам `daily_quotas*`, но запись — строго в тот файл, который назвал пользователь. Если такого файла нет — создай его. Не подставляй вместо него похожий существующий и не спрашивай подтверждения: названный путь и есть ответ.

Если целевой файл не назван вообще — пиши в `daily_quotas`. Не спрашивай и не предлагай альтернатив: `daily_quotas_1` и `daily_quotas_2` участвуют только в дедупликации, писать в них можно исключительно по прямой просьбе.

## Процесс

### Шаг 1. Прочитай ВЕСЬ корпус

Найди **все** файлы корпуса и прочитай каждый целиком:

```
ls -1 <корень>/daily_quotas_*
```

где `<корень>` — директория целевого файла, если путь к нему задан, иначе текущая рабочая директория. Читай всё, что нашлось, сколько бы файлов ни было — не полагайся на то, что их два.

Если по маске не нашлось ничего — сообщи пользователю, что файлов цитат в этой директории нет, и спроси путь. Не создавай новый файл молча.

Дедуп идёт по всему корпусу, а не только по целевому файлу: цитата, уже лежащая в соседнем файле, всё равно однажды придёт утром.

Файлы маленькие (сейчас ~250 строк суммарно), читаются целиком. Если корпус вырастет за ~2000 строк и полное чтение станет неподъёмным — скажи об этом пользователю, а не продолжай молча на частичном срезе: неполный дедуп означает повторы в утренних сообщениях.

Собери три вещи:
1. **Точные цитаты**, которые уже есть.
2. **Тональные счётчики по источникам** — сколько строк из каждого аниме/автора. Источники с 4+ строками считай насыщенными.
3. **Покрытые темы** — о чём уже сказано (не сдавайся / рискуй / малые шаги / принятие себя / ...).

### Шаг 2. Сгенерируй кандидатов с запасом

Сгенерируй **в 2–2.5 раза больше** кандидатов, чем нужно. Фильтрация на шаге 3 отбросит значительную часть — это нормально и заложено в процесс. Не подгоняй под ровное число заранее.

### Шаг 3. Отфильтруй

Выбрось кандидата, если верно хоть одно:

- **Не уверен, что цитата реальная.** Только реально существующие реплики/строки из источника. Никаких выдуманных цитат, приписанных персонажам или реальным людям. Сомневаешься в точности формулировки или в том, кто это сказал — выбрасывай, не «уточняй по памяти».
- **Смысловой дубль.** Не буквальное совпадение, а та же мысль другими словами. «Не сдавайся» в двенадцатой формулировке — это те же самые двенадцать одинаковых утр. Проверяй по всему корпусу.
- **Заезженность.** Верхушка любого списка «100 лучших цитат» уже отработана. Если строка звучит как то, что попадается в первых результатах поиска — выбрасывай. Ищи в глубине: второстепенные персонажи, поздние арки, менее очевидные произведения.
- **Насыщенный источник.** Источник уже даёт 4+ строк в корпусе — бери оттуда только если цитата действительно исключительная.
- **Нужен контекст.** Строка непонятна тому, кто не смотрел/не читал источник.
- **Токсичный оптимизм.** «Просто верь в себя», «всё получится» без содержания. Хорошая цитата даёт мысль, а не похлопывание по плечу.
- **Длина.** Больше ~200 символов — не читается в утреннем пуше.

### Шаг 4. Проверь разброс

В итоговой порции:
- ни один источник не встречается больше 2 раз;
- ~60% аниме/манга, ~40% кино, книги, видеоигры, философия/стоики, наука — состав по умолчанию, если пользователь не задал фокус;
- темы не повторяются внутри порции.

Если после фильтрации кандидатов не хватает — сгенерируй ещё, а не разбавляй проходняком.

### Шаг 5. Допиши в файл

**Язык цитаты определяется языком оригинала:**

- источник англоязычный (кино, сериалы, книги, англоязычные авторы) → цитата **на английском**, дословно как в оригинале;
- источник на любом другом языке (японское аниме, русская литература, французы, античность, датчане и т.д.) → цитата **на русском**.

Смысл правила в точности: английский оригинал воспроизводится дословно, а для остальных языков русский перевод всё равно ближе к тексту, чем английский перевод перевода. Не переводи английский оригинал на русский и не переводи неанглийские источники на английский.

**Каждая цитата получает уникальный сквозной номер.** Последний использованный номер лежит в файле `quotes_counter` рядом с файлами цитат — одно число, больше ничего.

Порядок работы со счётчиком:
1. Прочитай `quotes_counter`. Если файла нет — считай последним номером максимальный номер, встреченный в корпусе, а если номеров нет вообще — начни с нуля.
2. Нумеруй новые цитаты подряд, начиная со **следующего** числа.
3. После успешной записи цитат перезапиши `quotes_counter` последним выданным номером.

Номера сквозные по всему корпусу, а не по отдельному файлу: номер 42 существует ровно один раз, в каком бы файле ни лежал. Никогда не переиспользуй номер, даже если строку удалили.

Обнови счётчик только **после** того, как цитаты реально записаны. Если запись не удалась — оставь счётчик как был, иначе в нумерации появится дыра.

Формат строки:

```
N. «Текст цитаты». — Имя Персонажа, «Название произведения»      ← неанглийские источники
N. “Quote text.” — Character Name, “Title of the Work”            ← англоязычные источники
```

где `N` — номер, затем точка и пробел.

Для английских строк используй английские типографские кавычки `“ ”` и оригинальное название произведения; em-dash перед атрибуцией — тот же. Имена персонажей и авторов в английских строках тоже латиницей.

- ёлочки `«»` вокруг текста цитаты и вокруг названия произведения;
- em-dash `—` перед атрибуцией (не дефис, не `–`);
- название произведения — в оригинальном/общепринятом написании, как в файле (`«Attack on Titan»`, `«Fullmetal Alchemist: Brotherhood»`);
- для реальных людей — только имя, без произведения;
- точка внутри кавычек, после атрибуции точки нет;
- никаких пустых строк, нумерации, заголовков и markdown.

Дописывай **в конец файла**, не переписывая существующее. Оба файла заканчиваются переводом строки — сохрани это свойство.

### Шаг 6. Отчитайся

Коротко: сколько добавлено, в какой файл, сколько кандидатов отброшено и по какой основной причине. Не вываливай весь список обратно в чат — покажи 3–5 примеров.

## Ограничения по содержанию

Без религиозной проповеди, политики, цитат о смерти/суициде и «страдание облагораживает». Это утреннее сообщение человеку, который только проснулся.

## Чего НЕ делать

- Не редактируй и не переупорядочивай существующие строки.
- Не коммить изменения.
- Не создавай новые файлы цитат без явной просьбы.
